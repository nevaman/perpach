# Perpach Mining website

Static, server-renderable Phase 1 public website for `perpach.com/mining`. Content intentionally avoids unverified legal, technical, production and personnel claims.

## Run

```bash
npm run build
npm test
npm run serve
```

The host must support the Netlify-style `_redirects` file or reproduce its exact-root `307` rule. Forms use Netlify Forms markup and require equivalent server-side routing, validation, retention and spam controls if deployed elsewhere.
